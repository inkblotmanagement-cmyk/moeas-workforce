# Security and safety policy

## Reporting

Please report security problems **privately** by email to inkblotmanagement@gmail.com
with the subject "Security: <repository name>". Do not open a public issue.

Include what you did, what happened, and what you expected. We aim to reply within 7 days.

## What counts

- Normal security bugs (for example, an API key check that can be bypassed).
- **Safety bypasses.** Any request that should be stopped but gets `ALLOW`, especially
  self-harm or stalking requests, or any way to make the code skip the JMGL check or stop
  failing closed. Please share the exact text you used.

Accuracy misses that come from the JMGL engine itself may be forwarded to
https://github.com/inkblotmanagement-cmyk/JacksonMoralGovernanceLayer.

## Supported versions

Only the latest commit on `main` (and `public-release`, if published) is supported.

## Limits

This code is a pilot-stage governance check on text. It is not a guarantee against harm and
has not been independently evaluated. Keep a person in the loop for anything important.
If you or someone you know is in crisis, in the US call or text 988, or call 911 in an
emergency.
